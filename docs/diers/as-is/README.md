## Зачем это здесь

Три применения:

1. **Вход для [сопоставления с ТЗ](../gap-analysis.md)** — что уже есть, чего нет.
2. **Источник предметных знаний**, которые переиспользуются: словарь параметров DICAM,
   устройство CSV-экспорта, карта мышц ЭМГ (Приложения А и В).
3. **Реестр рисков legacy-модуля**, пока он остаётся в проде (Приложение Г).

## Короткая сводка

- 16 эндпоинтов, две таблицы с JSON в `text`-полях, без FK и версионирования.
- Два React-компонента: пациентский (не смонтирован ни на одной странице) и
  врачебный read-only.
- Сравнение — арифметическая разность двух произвольных исследований без порога
  значимости и без понятия нейтрали.
- Тестов нет.
