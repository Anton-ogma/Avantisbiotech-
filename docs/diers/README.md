## Что это за модуль в двух абзацах

Модуль хранит и сравнивает во времени результаты инструментальных исследований
опорно-двигательного аппарата на оборудовании DIERS International: оптическая
3D/4D-топография спины **formetric 4D** (параметры позвоночника, постуры,
походки) и поверхностная ЭМГ **Myoline**. Клиническая задача — показать врачу и
пациенту динамику «до / после» курса лечения, а не единичный снимок.

Прибор в контур не заведён: у DIERS formetric нет публичного REST API, и
эндпоинт синхронизации — намеренная задокументированная заглушка. Рабочий путь
получения данных один — ручная выгрузка CSV из DICAM Software и импорт в систему;
второй путь — ручной ввод параметров в форму.

## Ключевые факты

- **Бэкенд:** 16 эндпоинтов, `server/routes.ts:5690-5915` + `server/doctor_routes.ts:54-88`.
- **Хранение:** две таблицы, параметры — JSON в `text`-полях, без FK.
- **UI:** два компонента — пациентский (884 строки) и врачебный read-only (459 строк).
- **Состояние:** пациентский компонент **не смонтирован ни на одной странице**;
  сравнение у врача уходит в пациентский эндпоинт и всегда возвращает 404.
- **Тестов нет.**

Полный разбор состояния — [Приложение Г](./annex-d-defects-backlog.md);
два пункта P0 закрывают оба блокера.
